# Проверка интерфейса

Команда: `python -m tests.ui_check`. Результат: OK.

Chrome headless, настольный экран 1200×900 и мобильный 390×844.
Отдельная PostgreSQL, настоящие API и подпись учебной личности Telegram.
Проверено: поступление через форму; заказ и платёж; расход 100 ₽; поток 1100 ₽ и результат 400 ₽;
возврат в два шага; поток −100 ₽; мобильный склад без горизонтального переполнения;
ошибка при отключении сети и успешное обновление после восстановления; ошибок JavaScript нет.

SDK Telegram заменён только в тестовом браузере. Это не проверка запуска из реального Telegram.
Скриншоты содержат только учебные данные: `screenshots/finance-desktop.png`, `screenshots/stock-mobile.png`.
